# SPAOI: Sistema Predictivo de Alertas y Optimización de Inventarios

## Descripción del Proyecto

**SPAOI** es una solución de analítica preventiva diseñada para optimizar la gestión de stock y mitigar riesgos en la cadena de suministro. El sistema analiza de forma continua existencias, hábitos de consumo, lotes y tiempos de abastecimiento para anticiparse a incidencias operativas y facilitar la toma de decisiones estratégicas.

### Funcionalidades Clave
- **Detección de Desabastecimiento:** Identificación temprana de riesgos de rotura de stock antes de que afecten la disponibilidad.
- **Control de Caducidades:** Monitoreo y alerta preventiva de productos o lotes próximos a vencer para reducir pérdidas.
- **Análisis de Sobreinventario y Rotación:** Diagnóstico de artículos con baja salida para evitar costos por almacenamiento excesivo.
- **Alertas y Recomendaciones:** Generación de sugerencias automáticas para la reposición o redistribución eficiente del inventario.
